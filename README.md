# PIJAR SMAN 8 Yogyakarta – Aplikasi Android

WebView full screen untuk https://portal.pijarsekolah.id/sman8yogyakarta

- Pojok kiri atas  : tombol refresh
- Pojok kanan atas : tombol mode desktop (ikon jadi biru saat aktif)
- Tombol Back      : kembali ke halaman sebelumnya, keluar jika sudah di awal
- Upload & unduh file didukung

## Cara membuat APK
1. Pasang Android Studio (https://developer.android.com/studio).
2. File > Open > pilih folder `PijarSMAN8`, tunggu Gradle sync selesai
   (jika diminta membuat/memperbarui Gradle wrapper, pilih OK).
3. Coba di HP: sambungkan HP (USB debugging aktif) lalu klik Run.
4. Buat APK: Build > Build Bundle(s) / APK(s) > Build APK(s).
   Hasil: `app/build/outputs/apk/debug/app-debug.apk` — kirim ke HP lalu pasang.
